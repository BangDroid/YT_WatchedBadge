 # YT_WatchedBadge
Adds a "Watched" cover to any watched videos on YouTube. Includes options for progress bar configuration: Hide the progress bar alltogether, like the previous version; hide only 100% watched progress bars, or just obscure them.

Compatible with YouTube's own light and dark themes, no guaranteed compatibility for other userstyle custom themes.
The userstyle now includes a build in SVG image for the cover, saving size and memory and better scaling at various thumbnail sizes. The progress bar is now retained allowing progress tracking, but **this is still buggy on YouTube's end.**
**Occasionally a video will be attributed 100% watch progress when only a small amount has actually been watched, and even instances where the progrss bar is full on videos that are not watched at all and don't even exist in the history. Subsequently, the Watched cover is misappropriately applied.** It's an issue on YouTube's end, there's nothing I can do about it.
