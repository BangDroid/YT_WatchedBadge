 # YT_WatchedBadge
Adds a "Watched" cover to watched videos on YouTube.

Compatible with YouTube's own light and dark themes, no guaranteed compatibility for other userstyle custom themes. But provided they leave the progress bar alone (&lt;ytd-thumbnail-overlay-resume-playback-renderer&gt; and children, it shouldn't be an issue.)
The userstyle now includes a build in SVG image for the cover. The progress bar is now retained allowing progress tracking, but this is still buggy on YouTube's end. (Occasionally a video will be attributed 100% watch progress when only a small amount has actually been watched, and even instances where the progrss bar is full on videos that are not watched at all and don't even exist in the history. Subsequently, the Watched cover is misappropriately applied.)
